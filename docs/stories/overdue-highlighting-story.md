# Story: Highlight overdue tasks in the list

## Acceptance Criteria

- Overdue tasks are visually distinct from non-overdue tasks.
- The visual treatment makes overdue tasks easy to identify in the task list.
- This work is treated as Post-MVP.

## Technical Requirements

- Apply a distinct visual style to overdue tasks.
- Determine overdue state from each task's due date.
- Keep overdue highlighting separate from MVP delivery.
