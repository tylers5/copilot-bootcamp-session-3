# Story: Persist due date and priority locally

## Acceptance Criteria

- Due date and priority values are saved with each task in local storage.
- Task data remains available after a page refresh.
- MVP enhancements do not require backend or external storage changes.

## Technical Requirements

- Update local task persistence to store `dueDate` and `priority`.
- Keep MVP data handling local to the application.
- Avoid introducing backend dependencies for MVP task metadata.
