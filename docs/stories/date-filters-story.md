# Story: Add All Today and Overdue filters

## Acceptance Criteria

- The task list supports `All`, `Today`, and `Overdue` views.
- Users can switch between the available filter views.
- The `Today` view shows tasks due today.
- The `Overdue` view shows tasks past their due date.

## Technical Requirements

- Add filter controls for `All`, `Today`, and `Overdue`.
- Implement filtering logic based on each task's `dueDate`.
- Apply date-based filtering using the locally stored task data.
